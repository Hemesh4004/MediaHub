# Editorial Module — MediaHub

## Description
This module handles the Editorial functionality of the MediaHub platform.

## Package Structure
```
com.mediahub.editorial
├── model/          — POJO / Model classes
├── repository/     — Database layer (JDBC queries)
├── service/        — Business logic layer
└── controller/     — REST API endpoints
```

## Branch
`feature/Editorial`

## How to Run
1. Configure `application.properties` with your MySQL credentials
2. Run `EditorialApplication.java` as a Spring Boot application
