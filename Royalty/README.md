# Royalty Module — MediaHub

## Description
This module handles the Royalty functionality of the MediaHub platform.

## Package Structure
```
com.mediahub.royalty
├── model/          — POJO / Model classes
├── repository/     — Database layer (JDBC queries)
├── service/        — Business logic layer
└── controller/     — REST API endpoints
```

## Branch
`feature/Royalty`

## How to Run
1. Configure `application.properties` with your MySQL credentials
2. Run `RoyaltyApplication.java` as a Spring Boot application
