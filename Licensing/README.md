# Licensing Module — MediaHub

## Description
This module handles the Licensing functionality of the MediaHub platform.

## Package Structure
```
com.mediahub.licensing
├── model/          — POJO / Model classes
├── repository/     — Database layer (JDBC queries)
├── service/        — Business logic layer
└── controller/     — REST API endpoints
```

## Branch
`feature/Licensing`

## How to Run
1. Configure `application.properties` with your MySQL credentials
2. Run `LicensingApplication.java` as a Spring Boot application
