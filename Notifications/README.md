# Notifications Module — MediaHub

## Description
This module handles the Notifications functionality of the MediaHub platform.

## Package Structure
```
com.mediahub.notifications
├── model/          — POJO / Model classes
├── repository/     — Database layer (JDBC queries)
├── service/        — Business logic layer
└── controller/     — REST API endpoints
```

## Branch
`feature/Notifications`

## How to Run
1. Configure `application.properties` with your MySQL credentials
2. Run `NotificationsApplication.java` as a Spring Boot application
