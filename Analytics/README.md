# Analytics Module — MediaHub

## Description
This module handles the Analytics functionality of the MediaHub platform.

## Package Structure
```
com.mediahub.analytics
├── model/          — POJO / Model classes
├── repository/     — Database layer (JDBC queries)
├── service/        — Business logic layer
└── controller/     — REST API endpoints
```

## Branch
`feature/Analytics`

## How to Run
1. Configure `application.properties` with your MySQL credentials
2. Run `AnalyticsApplication.java` as a Spring Boot application
